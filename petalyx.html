Petalyx™

An intuitive, low-friction word-association UI.

Try the Petalyx™ demo

How it works
  • For each prompt word, users choose from five response words arranged radially, plus ‘None of the Above’.
  • Both the chosen response and all non-chosen options are treated as structurally informative.
  • Response time is captured and normalised against individual motor speed, within-session fatigue, time-of-day variation, and demographic baseline.
  • Individual session data is destroyed on the user's device before any transmission. Only aggregate coordinate values are transmitted — no login, no cookies, no email address, and IP addresses are not stored or used to track users.
